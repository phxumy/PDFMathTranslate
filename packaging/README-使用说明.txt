PDFMathTranslate Codex 增强桌面版（非官方）
===============================================

一、安装和启动
1. 在本项目 GitHub 发行页面下载 PDFMathTranslate-Codex-Setup-win64.exe。
2. 双击安装，默认只为当前 Windows 用户安装，无需单独安装 Python 或 Node.js。
   安装后可从开始菜单启动，也可选择创建桌面快捷方式。
3. 在软件里的“Codex 账号与剩余额度”区域查看账号或发起登录，按提示完成官方账号验证。
   内置 CLI 从 .7.2 起使用独立账号，升级后需首次登录；不会复制原有 Codex 凭据。
   指定用户自己的 CLI 时，沿用该 CLI 的登录与配置，切换会影响该 CLI 的账号。
   可刷新账号邮箱、套餐、额度窗口剩余百分比和重置时间；查询失败显示暂不可用。
   不再需要先找外部 CMD 文件登录；旧 Login-Codex.cmd 仅保留作兼容入口。
4. 可一次选择多个 PDF，点击“翻译 / 继续队列”后按列表顺序逐个处理。
   队列已有文件时，也可继续将 PDF 拖到上传区域，追加到现有列表末尾。
   已完成文件的译文和双语 PDF 会保留在队列下载区。
   失败或点击“停止队列”会暂停后续文件；同一窗口重试相同文件和设置会跳过已完成结果。
5. 翻译前后使用同一组翻页按钮。未译页仍显示原文，已译页会原位替换；完成后保留耗时。
6. 点击“翻译日志与本地文件管理”查看任务时间、错误、页码和缓存情况，下载原文/译文或导出日志。
   文件被清理后显示“已删除”。作者、期刊、年份按可用本地信息识别，缺失时显示“未识别”。
7. 先保存需要的译文，再勾选确认删除所选本地文件或清空标准翻译缓存。
   翻译或更新中不可清理；BabelDOC 自有缓存不在此统计内。旧版本历史不强制导入。

二、并行与预计时间
在“模型与服务设置”中，模型和推理强度可从下拉框选择，也可手动输入。
启动或切换到 Codex 时会读取模型目录；点击“刷新模型与推理强度”可重新读取。
读取失败时保留当前设置。可填写 GPT-6.1 Terra 的精确 ID：gpt-6.1-terra。
目录不等于实际调用权限；当前翻译后端支持的推理强度最高为 max。
可选 Codex Fast 模式请求账号支持的快速服务档位，取决于模型与账号可用性，可能消耗更多额度。
“2 倍并行”提高同时处理的翻译任务数量，不保证任何文档都能严格缩短一半时间。
具体速度取决于模型、网络、段落长度、账号限速与文档布局。遇到限速时降低并行数。
预计剩余时间按照实际完成的翻译工作滚动估计，刚开始的少量样本可能不稳定。

三、检查与安装更新
在软件内点击检查更新；发现新版本后，明确点击下载并安装，软件才会下载。
只访问 phxumy/PDFMathTranslate 的 GitHub 正式发行，核对安装包大小与 SHA-256。
校验成功后关闭当前窗口并安装，完成后重新打开。翻译过程中禁止安装更新。
下载或校验失败不会运行安装包。浏览器模式请通过发行页面下载安装。

从旧 ZIP 升级时，运行本版 EXE 安装程序即可；旧解压目录和其中的译文不会删除。
已有软件设置会沿用用户目录中的数据。内置 CLI 首次启用独立账号需重新登录。
可确认新版正常后自行处理旧目录。

四、文件位置与卸载
软件设置：%USERPROFILE%\.config\PDFMathTranslate
新桌面版翻译工作区：%USERPROFILE%\.config\PDFMathTranslate\workspace
内置 Codex 独立登录：%USERPROFILE%\.config\PDFMathTranslate\codex
外部 Codex：沿用该 CLI 的 CODEX_HOME 与凭据存储配置。
内置 CLI 的登录、切换和退出不修改桌面端或个人 CLI 的凭据。
登录隔离不增加账号额度；两端使用同一账号时仍消耗该账号的服务额度。
升级和卸载不删除这些用户数据。卸载入口在 Windows 设置的“已安装的应用”中。

五、发行内容
内含官方稳定版 Codex CLI 0.163.0、Node.js 24.19.0、锁定版本的运行依赖及离线版面/OCR/字体资源。
不包含任何人的账号、凭据、API Key、套餐或免费额度。云端翻译仍需网络并消耗服务额度。
此软件并非 OpenAI 或上游项目的官方发行。

适用 Windows 10/11 x64；桌面窗口需要 Microsoft Edge WebView2。
本社区安装包没有代码签名，Windows 可能提示“未知发布者”。请从本仓库发行页面下载，
可使用同页 SHA256SUMS.txt 核对文件完整性。缺少运行组件时从微软官网下载 WebView2
或 Visual C++ x64 Redistributable。
