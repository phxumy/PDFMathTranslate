BabelDOC offline assets - source and license notice
===================================================

This release contains the offline asset archive generated by the locked
BabelDOC package. The archive contains document-layout/OCR models and fonts.
Each included asset remains governed by its own upstream license; inclusion
does not relicense it under PDFMathTranslate's AGPL license.

Primary asset manifest and source repository:
https://github.com/funstory-ai/BabelDOC-Assets
https://github.com/funstory-ai/BabelDOC

Model sources referenced by BabelDOC's asset manifest include:
https://huggingface.co/RapidAI/RapidOCR
https://huggingface.co/juliozhao/DocLayout-YOLO-DocStructBench

Font projects represented in the generated archive include:
https://github.com/notofonts/noto-cjk
https://github.com/lxgw/LxgwWenKai
https://github.com/ButTaiwan/gonoto-fonts

For the exact BabelDOC package version and complete dependency resolution, see
BUILD-INFO.txt and the uv.lock file in the corresponding source tag.
