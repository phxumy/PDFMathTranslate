# ChatGPT 聊天翻译（本地浏览器）

新增服务 **ChatGPT 聊天** 使用 Oracle 的浏览器引擎，将分批正文发送到普通 ChatGPT 网页，再交给原有 PDF 流程校验、排版。此路径不启动 Codex，不调用模型 API，也不自动切换到其他翻译服务。

## 使用

1. 在翻译服务中选择 **ChatGPT 聊天**。
2. 点击 **登录 ChatGPT / 打开登录窗口**，在专用 Chrome 窗口完成登录。
3. 点击 **刷新模型与连接状态**，选择网页实际显示的模型和推理强度。
4. 选择 PDF 并开始翻译。翻译时保持专用浏览器运行，可以最小化。

模型列表不写死。切换模型后会重新读取该模型的强度选项；网页未提供强度控制时下拉框为空。网页结构无法识别、选项不可用或无法确认所选模型时，停止发送并显示原因。首次登录和会话过期后的登录由用户在网页完成。

当前支持标准 PDFMathTranslate 排版流程，暂不支持此服务与 Use BabelDOC 组合。浏览器翻译串行处理；保留既有 Codex 和其他服务。

## 登录错误

如果登录页显示 `Route Error` 或 `Invalid content type: text/html`，软件会报告登录错误。再次点击 **登录 ChatGPT / 打开登录窗口** 会从首页重新开始登录；正常的账号输入页和网页验证页不会被刷新，浏览器配置和 Cookie 也不会被清除。

这类错误可能伴随认证请求返回 HTTP 403。它表示请求被拒绝，仅凭此状态不能判断密码错误或具体网络原因。请在专用窗口完成网站要求的验证；如果仍失败，先确认日常浏览器使用相同网络能否正常登录，再排查当前 VPN 或代理。程序不会绕过网站验证。

如果停留在“请稍候…”人机验证页，软件会暂停并显示等待验证。即使页面同时保留旧错误信息，点击登录也不会重新加载正在验证的页面。验证反复出现时，浏览器接入尚不可用；界面测试通过不代表网站一定接受当前浏览器会话。Cloudflare 的[官方排错说明](https://developers.cloudflare.com/cloudflare-challenges/troubleshooting/challenge-solve-issues/)列出了网络、浏览器配置和检测误判等原因；其[浏览器支持说明](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/)也明确指出不支持自动化浏览器完成生产环境验证。

本机在 2026-09-25 使用[Cloudflare 官方兼容性检测](https://debug.challenges.cloudflare.com/)得到 `Automated Browser Detected`，确认专用浏览器暴露程序控制状态。普通浏览器可打开 ChatGPT，但本模式真实登录仍被验证拦住。当前版本保留此实验入口并暂停翻译，未伪装浏览器或绕过验证。

Windows 下，如果 Chrome 重启后保存的调试端口过期，程序会从使用本软件专用配置的 Chrome 主进程查找实际监听端口，并校验连接身份。不会接管日常浏览器。

## 关闭、取消与继续

- 关闭专用浏览器：本地任务暂停，已完成的译文保留。网页上已经发送的请求可能仍在服务器继续生成。
- 关闭软件或点击取消：停止本地等待；不保证撤回已经发送的网页消息。浏览器和正在收取回答的工作进程可能继续运行。
- 恢复：重新打开软件，选择相同服务、模型和强度，点击打开浏览器并刷新，对同一 PDF 再次点击翻译。程序复用已保存结果，对未完成请求先读取原会话，不自动重发。
- 如果无法确认原会话和当前批次的对应关系，显示错误并保留记录。不能保证每次中断都能自动恢复，尤其是发送后尚未记录会话地址时被强制关闭。
- 已完成但 JSON 或段落数量不合要求的回答会保留。勾选 **Ignore cache** 后可创建新尝试；尚未完成或状态不明确的请求仍先恢复，避免重复提交。

恢复需要保持相关翻译设置一致。程序按请求内容、模型和推理强度识别批次，不是只按 PDF 文件名识别。

## 登录与日常聊天

专用 Chrome 配置默认保存在 `%LOCALAPPDATA%\PDFMathTranslate\ChatGPT\chrome-profile`。正常关闭软件或浏览器不会删除它；下次打开通常不必重新登录。会话过期、主动退出、账号撤销登录或手动清理配置后需要重新登录。

程序不读取或操作日常 Chrome 配置，也不操作 ChatGPT 桌面窗口。翻译会建立独立聊天，因此会进入同账号聊天历史；账号设置、部分模型偏好、登录变化和使用限制可能跨客户端同步。独立浏览器并不代表独立账号。

网页回答使用该账号普通 Chat 的访问权限和限制。这里没有官方 ChatGPT API 授权，也没有额度计量保证；程序只保证本实现的调用路径固定为浏览器，并在无法确认普通 Chat 模式时停止。

## 本地数据与组件

- 默认状态目录：`%LOCALAPPDATA%\PDFMathTranslate\ChatGPT`。
- 请求、原始回答和恢复信息：状态目录中的 `requests` 与 `oracle` 子目录。它们包含文档文本；登录配置包含登录状态，不应提交到 Git 或分享。
- 状态目录可用 `PDF2ZH_CHATGPT_STATE_DIR` 覆盖。
- Node.js 24 或以上；可用 `PDF2ZH_NODE_BIN` 指定可执行文件。
- Google Chrome；可用 `PDF2ZH_CHATGPT_CHROME_PATH` 指定路径。
- 浏览器组件固定依赖版本，见 `pdf2zh/browser_bridge/package-lock.json`。本地安装依赖时在该目录运行 `npm ci`。

网页界面变化可能需要更新浏览器适配器。没有从已登录账号实际完成测试前，应将动态选项和实际翻译视为待验证。
