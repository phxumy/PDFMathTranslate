# ChatGPT 聊天翻译（连接已登录的 Chrome）

服务 **ChatGPT 聊天** 使用 Oracle 的浏览器引擎，将分批正文发送到普通 ChatGPT 网页，再交给原有 PDF 流程校验、排版。此路径不启动 Codex，不调用模型 API，也不自动切换到其他翻译服务。

浏览器连接采用 Chrome 原生的连接授权：先在平时使用的 Google Chrome 中正常登录 ChatGPT，再允许软件连接这个已运行的浏览器。软件不启动旧版专用浏览器配置，也不复制 Cookie 或迁移登录状态。

## 首次连接

1. 自己打开平时使用的 **Google Chrome**，访问 ChatGPT 官网并完成正常登录。先确认在该窗口中能够正常聊天。
2. 在 Chrome 地址栏打开 `chrome://inspect/#remote-debugging`，开启页面提供的本机远程调试选项。如果当前 Chrome 没有该页面或选项，先更新 Chrome；软件不会自动修改启动参数或改用旧版专用配置。
3. 在 PDFMathTranslate 中选择 **ChatGPT 聊天**，点击 **连接已登录的 Chrome**。
4. Chrome 弹出连接授权时，由自己核对并点击允许。授权由 Chrome 管理；软件不会代替你确认。
5. 点击 **刷新模型与连接状态**，选择网页实际提供的模型和推理强度，然后选择 PDF 开始翻译。

翻译时保持该 Chrome 运行，可以最小化窗口。连接组件在本机常驻，后续批次复用连接，避免每段文字重新连接；空闲约 30 分钟后自动退出。Chrome 或连接组件重启、连接中断或授权被撤销后，可能需要再次点击连接并在 Chrome 中允许。

**Chrome 的调试授权和 ChatGPT 账号登录是两件事。**重新允许连接不代表必须重新登录 ChatGPT；是否需要重新登录，以正常 Chrome 中的账号状态为准。

## 模型与推理强度

模型列表不写死，来自当前 Chrome 登录账号的网页。切换模型后重新读取可用推理强度；支持读取网页菜单和可识别的强度滑块。网页没有强度控制时，下拉框为空。

网页结构无法识别、选项不可用或无法确认所选模型与普通 Chat 模式时，程序停止发送并显示原因，不猜测模型，也不自动转到 Work 或其他服务。不同账号和网页版本的选项可能不同。

当前支持标准 PDFMathTranslate 排版流程，暂不支持此服务与 **Use BabelDOC** 组合。浏览器翻译串行处理；既有 Codex 和其他翻译服务继续保留。

## 一个翻译任务使用一个对话

一份 PDF 的同一个翻译任务只创建一个 ChatGPT 对话，所有待译批次依次追加到这个对话。读取缓存不会发送消息；已完成批次需要重新翻译时，也继续使用该任务的对话。

译文语言以软件的目标语言选项为准，与 ChatGPT 网页界面语言无关。连接组件不会修改网页的语言偏好。

任务按原始 PDF 内容、页码范围、语言、提示词、模型和推理强度等翻译设置识别。相同文件和设置可恢复原任务；不同文件或影响翻译的设置变化会形成新任务。仅修改文件名、等待超时或线程数，不会因此新建对话。

重新打开软件或 Chrome 后，程序优先回到已保存的任务对话。上一批发送结果尚不明确、原对话身份无法核实，或网页已无法继续该对话时，任务暂停并保留记录，不会自动新建对话继续发送。

## 登录、验证和授权问题

- **普通 Chrome 也无法登录 ChatGPT**：先在正常网页中完成网站要求的登录或验证。连接组件不提供绕过验证码、伪装浏览器或替代账号登录的功能。
- **Chrome 等待允许连接**：查看 Chrome 的授权提示。拒绝或关闭提示后，需要再次点击连接；不要把调试授权提示当作 ChatGPT 登录失效。
- **未开启调试或 Chrome 不支持该功能**：检查 `chrome://inspect/#remote-debugging`。软件应报告连接不可用，不自动启动专用浏览器。
- **软件已经连接，但网页要求重新登录或验证**：先在 Chrome 中处理网页提示，再回到软件刷新状态。不要反复启动翻译来尝试跳过验证。

这次连接方式调整不等于网站验证问题已经解决。正常网页登录、原生连接授权、模型选项读取和实际翻译需要分别验证；本地自动测试通过也不能替代登录账号的完整翻译测试。

## 关闭、取消与继续

- **关闭 Chrome**：本地任务暂停，已完成译文保留。已经发送的请求可能仍在 ChatGPT 服务器继续生成。
- **关闭软件或点击取消**：停止本地等待，不保证撤回已经发送的网页消息。浏览器或收取回答的组件可能继续运行。
- **恢复同一任务**：重新打开 Chrome 和软件，按需允许连接，选择相同服务、模型和强度，对同一 PDF 再次点击翻译。程序复用已保存结果，对未完成请求先读取原会话，不自动重发。
- **无法确认原会话对应哪一批**：显示错误并保留记录，不采用其他聊天的回答。发送后尚未记录会话地址就被强制关闭等情况，可能无法自动恢复。
- **已完成但格式不合要求**：原始回答保留。勾选 **Ignore cache** 可为已完成批次创建新尝试；尚未完成或状态不明确的请求仍先恢复。

恢复要求保持相关翻译设置一致。程序同时核对任务、原对话及批次内容，不只按 PDF 文件名识别。

## 下次使用及日常聊天

登录状态由平时使用的 Chrome 保存。正常关闭软件或 Chrome 不会清除登录状态；下次通常只需重新连接，必要时允许 Chrome 调试连接。会话过期、主动退出、账号撤销登录或清理浏览器数据后，才可能需要重新登录 ChatGPT。

软件使用自己创建的翻译标签页，不向你的其他聊天标签页发送文字，也不操作 ChatGPT 桌面窗口。你可以继续在其他标签页或桌面端聊天；请勿在翻译标签页中另外输入消息、切换模型或跳转到其他会话。

软件自建标签页使用网页标准的“不自动翻译”标记，避免 Chrome 的页面翻译改写模型菜单、输入原文或回答。此标记仅作用于这些标签页，不修改 Chrome 的全局翻译设置。

同账号的聊天历史、账号设置、部分模型偏好、登录变化和使用限制仍可能跨网页和桌面端同步。Chrome 调试授权本身也不是仅限某个翻译标签页的权限；软件只操作自建标签页是本实现遵守的范围。

网页回答使用该账号普通 Chat 的访问权限和限制。这不是官方 ChatGPT API 授权，也不是额度计量保证；本实现固定使用浏览器路径，并在不能确认普通 Chat 模式时停止。

## 本地数据与组件

- 默认状态目录：`%LOCALAPPDATA%\PDFMathTranslate\ChatGPT`。
- 请求、原始回答和恢复信息保存在状态目录中，包含文档文本，不应提交到 Git 或分享。
- ChatGPT 登录状态保留在自己的 Chrome 配置中；软件不读取或复制 Cookie 文件。旧版专用 `chrome-profile` 不再作为连接入口。
- 状态目录可用 `PDF2ZH_CHATGPT_STATE_DIR` 覆盖。
- 需要 Node.js 24 或以上，可用 `PDF2ZH_NODE_BIN` 指定可执行文件。
- 需要已运行、已登录且支持原生调试授权的 Google Chrome。
- 浏览器组件依赖版本固定在 `pdf2zh/browser_bridge/package-lock.json`；本地安装依赖使用该目录中的 `npm ci`。
